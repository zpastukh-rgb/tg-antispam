Чеклист: если токены/пароли светились в общем чате, скриншоте или логах
================================================================

1) Telegram: BotFather → /revoke для бота → новый BOT_TOKEN. Обновить во всех сервисах Railway (бот, API), redeploy.

2) Railway: Account → Tokens → удалить старый токен, создать новый → RAILWAY_API_TOKEN только в сервисе API, redeploy API.

3) Postgres: сменить пароль пользователя БД → обновить DATABASE_URL (или PG*) на боте и API, redeploy.

4) ЮKassa: кабинет → ключи API → перевыпустить live/test секреты при необходимости; обновить переменные на API; при смене вебхука — новый YOOKASSA_WEBHOOK_SECRET.

5) SMTP и прочие пароли в Variables — заменить и redeploy затронутые сервисы.

Проверка миграции chat_id на копии БД (staging / dump)
======================================================
Сделайте бэкап. На копии можно вызвать из Python один раз remap_group_chat_ids(old_telegram_id, new_telegram_id)
после ручной проверки: SELECT table_name FROM information_schema.columns
WHERE column_name IN ('chat_id','message_chat_id') AND table_schema IN ('public','main');
убедитесь, что кастомные таблицы с chat_id попали в выдачу — код теперь обходит их автоматически при переносе.
